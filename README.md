# Visual Design Director

Навык дизайн-директора для агента: помогает выбрать визуальное направление и довести его до конкретного дизайна сайта, презентации или дашборда. Связывает композицию, типографику, данные и движение с задачей пользователя. Поддерживает также отдельную спецификацию и предметное ревью.

Навык задаёт дизайн и критерии проверки. Для создания файлов, рендера и публикации он использует подходящие инструменты среды и профильные навыки; сам репозиторий не содержит движок сайта или генератор презентаций.

## Что внутри

- [SKILL.md](SKILL.md) — контекст, арт-дирекшен, визуальная система, выбор формата и проверка результата.
- [Типографика](references/typography.md) — кириллица, российские авторы, шрифтовая проба, доставка и переносимость.
- [Движение](references/motion.md) — CSS, Motion, View Transitions, reduced-motion и проверка эффектов.
- [Форматы и QA](references/formats-and-qa.md) — отдельные сценарии для сайта, слайдов и дашборда.
- [Метаданные агента](agents/openai.yaml) — название, пример вызова и разрешённый автоматический выбор навыка.

## Для каких задач

**Сайты.** Выразительное направление, структура и ключевое действие, адаптация, состояния компонентов, доступная навигация и осмысленная анимация.

**Презентации.** Тезис и доказательство каждого слайда, сетка и типографическая иерархия под условия показа, редактируемость и проверка конечного экспорта.

**Дашборды.** Выбор диаграммы под вопрос пользователя, сопоставимые периоды и единицы, базы сравнения KPI, фильтры, таблицы и состояния данных. Демонстрационные данные должны быть обозначены.

Стек, шаблон и бренд пользователя имеют приоритет. Навык не делает стекло, градиенты, 3D или параллакс обязательными элементами дизайна.

## Кириллица и шрифты

В подборке есть шесть гарнитур. Происхождение шрифта и поддержка кириллицы рассматриваются отдельно; конкретные файлы, начертания, символы и условия использования необходимо проверять перед выпуском. Источники и ограничения приведены в [типографическом reference](references/typography.md).

| Гарнитура | Статус выбранного источника | Возможная роль |
| --- | --- | --- |
| Golos Text | Открытая, OFL; Paratype, Александра Королькова и Виталий Кузьмин | Русскоязычный интерфейс, таблицы и подписи |
| PT Sans | Дистрибуция Google Fonts — OFL; ParaType, Королькова, Умпелева и Ефимов | Документальный тон, читаемый основной текст |
| Manrope | Открытая, OFL; поддерживает кириллицу | Крупный продуктовый набор и заголовки |
| Literata | Открытая, OFL; TypeTogether, кириллица и настоящие курсивы | Редакционный текст и выразительные слайды |
| Graphik Cyrillic | Коммерческая; кириллица Ильи Рудермана / CSTM Fonts | Брендовый гротеск при наличии соответствующих прав |
| TT Commons Pro | Коммерческая; TypeType, расширенная кириллица | Продуктовая система; trial используется для оценки |

Бинарные файлы шрифтов в репозиторий не включены. Открытая лицензия сохраняет свои условия; для коммерческих гарнитур различаются web, desktop, app и другие сценарии. Подключение семейства в CSS не доказывает правильный рендер кириллицы или поддержку табличных цифр.

## Установка

Клонируйте репозиторий в личный каталог навыков. Каталог назначения должен быть свободен.

```sh
mkdir -p ~/.agents/skills
git clone https://github.com/AnDeulin/visual-design-director.git ~/.agents/skills/visual-design-director
```

Это установка в личный каталог навыков. Проверьте, что используемый агент обнаруживает этот каталог и видит `visual-design-director`. Автоматический выбор разрешён в метаданных; доступность в конкретной среде зависит от её механизма загрузки навыков. Для явного вызова укажите `$visual-design-director` в запросе.

## Примеры вызовов

```text
Используй $visual-design-director. Подготовь дизайн-спецификацию
русскоязычного дашборда продаж: светлый деловой стиль, только открытые
шрифты, понятные KPI и диаграммы. Пока не создавай сайт или файл.
```

```text
Используй $visual-design-director и доступный навык создания сайтов.
Сделай сайт для моего сервиса по приложенному контенту. Нужны сильная
типографика с кириллицей, адаптация и аккуратная анимация с reduced-motion.
```

```text
Используй $visual-design-director вместе с профильным навыком презентаций.
Создай три слайда для руководства из приложенных данных. Сохрани
запрошенный формат и проверь слайды в целевом рендерере.
```

```text
Примени $visual-design-director для ревью этого интерфейса.
Назови конкретные проблемы композиции, русского набора, диаграмм
и движения, затем предложи исправления с учётом существующего бренда.
```

## Работа с рендерером

При реализации сочетайте дизайн-навык с доступным workflow: например, Sites для сайта, Presentations для слайдов или Spreadsheets для табличного файла. Читайте инструкции реально доступного навыка; его наличие нельзя предполагать по имени. При отсутствии профильного навыка нужен подходящий разрешённый runtime.

Дизайн-спецификация не подтверждает итоговый вид. Созданный результат проверяется в целевом браузере или приложении: шрифты, русский текст, переполнения, взаимодействия, клавиатура, контраст, движение и экспорт. Код и скриншот не доказывают полную доступность интерфейса. Непроверенные части следует обозначать прямо.

## Что фактически проверено

Выполнен прикладной тест на запрос о русскоязычном дашборде продаж и трёх слайдах для руководства: светлый деловой бренд, только открытые шрифты, явно обозначенные демо-данные и отсутствие запроса на создание сайта или презентационного файла.

Результатом стала конкретная спецификация: выбран Golos Text, заданы палитра и типографическая иерархия, сетка, диаграммы, состояния, поведение фильтров и сценарий трёх слайдов. Арифметика демо-данных и контраст заданных сплошных цветовых пар рассчитаны отдельно; источники OFL, покрытия кириллицы и reduced-motion сверены с первичными страницами.

В этом тесте сайт и презентация не создавались. Не проверялись рендер, бинарный файл шрифта, реальная клавиатурная работа интерфейса, производительность и PPTX/PDF-экспорт. Тест подтверждает работу сценария спецификации; он не является проверкой качества готового визуального артефакта.
